4 · Payment gateway — one question first
Own merchant account ≠ Stripe, but the integration shape is the same
You'll collect card details, tokenize through your gateway, charge on order confirmation, and handle refunds through the same gateway. The invoicing system lives in the admin panel — every order gets a generated invoice tied to the gateway transaction ID. Refunds, chargebacks, and partial credits all managed from there.
What gateway are you using? (Authorize.net, NMI, Heartland, Braintree, something else?) The API shape varies significantly between them — this determines how the checkout and invoice layer gets built.
